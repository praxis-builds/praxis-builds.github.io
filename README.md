# Praxis Builds

**Practical digital solutions for real business friction.**

Praxis Builds is an independent digital studio in Canada creating focused websites, workflow automations, spreadsheet systems, lightweight web apps, and custom business tools.

[View the live portfolio](https://praxis-builds.github.io/)

## What we build

- Business websites that are fast, clear, and mobile-friendly
- Workflow automations for repetitive files, reports, and routine processes
- Spreadsheet systems for tracking, cleanup, planning, and reporting
- Lightweight web apps for focused business workflows
- Custom tools when off-the-shelf software creates unnecessary friction

Every project starts with one defined problem, one agreed outcome, and one clear handoff.

## How we work

1. **Understand** — define the real problem and the desired outcome.
2. **Scope** — agree on features, responsibilities, timeline, and finish line.
3. **Build and test** — review a working version and verify it against the scope.
4. **Hand off** — deliver the completed project with practical usage notes.

## Built with

The portfolio is a lightweight static site built with:

- Semantic HTML
- Modern CSS
- Vanilla JavaScript
- GitHub Pages
- Formspree for project inquiries

There are no frontend frameworks, package dependencies, analytics, or trackers.

## Run locally

Clone the repository and start a static server:

```bash
git clone https://github.com/praxis-builds/praxis-builds.github.io.git
cd praxis-builds.github.io
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).
